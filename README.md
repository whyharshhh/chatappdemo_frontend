# 💬 Real-Time Chat App

A modern full-stack real-time chat application built with **React**, **Node.js**, **Socket.IO**, and **MongoDB**. It supports **JWT authentication**, **real-time messaging**, **profile updates**, and shows **online users** — all wrapped in a clean, responsive UI. Deployed with **Vercel** (Frontend) and **Render** (Backend).

👉 **Frontend**: [chatappdemo-frontend.vercel.app](https://chatappdemo-frontend.vercel.app)

---

## 📦 Tech Stack

### 🔧 Backend:
- **Node.js**
- **Express**
- **MongoDB** with Mongoose
- **Socket.IO**
- **JWT** for Auth
- **Cloudinary** for Image Uploads
- **Render** for Deployment

### 🎨 Frontend:
- **React + Vite**
- **Zustand** for State Management
- **Tailwind CSS** + **DaisyUI**
- **Socket.IO Client**
- **Axios**
- **React Hot Toast**
- **Vercel** for Deployment

---

## 🧠 Features

- ✅ Secure Sign-up / Login with JWT
- 🧠 Persistent Login via Cookies
- 🗣 Real-time One-to-One Messaging (via Socket.IO)
- 👥 Online Users Indicator
- 🖼 Send Image Messages
- 🖊 Update Profile Info
- ⚡ Instant Toast Notifications
- 📱 Fully Responsive Design
